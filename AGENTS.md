## Agent skills

### Issue tracker

Local markdown under `.scratch/<feature>/` (specs, numbered issues, wayfinding maps). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout routed via `GLOSSARY-MAP.md` (`system-projects/`, `Luster-EG-System/`, `Schoolvoice/` shared with `Schoolvoice-PO/`) plus root and per-context `docs/adr/`. See `docs/agents/domain.md`.
